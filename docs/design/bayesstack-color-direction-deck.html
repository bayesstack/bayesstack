01 · What the current system says

The raw material is good.
The orchestration needs work.

The current teal is appropriate for a trusted education platform. The larger risk is visual drift: teal and slate systems coexist, while component CSS repeatedly hard-codes values instead of consuming one semantic contract.

Keep

Teal as the institutional anchor

#056766 / #0B6763 reads as composed, academic and distinctly less generic than the usual SaaS blue. It is already present in the brand assets, auth, super-admin and UI package.

Change

Make the neutral system intentional

Teal-tinted canvas values and Slate-like values are currently mixed. Let an airy blue-grey neutral system carry 85–90% of the product so the brand colour can actually feel special.

Limit

Do not make every useful colour a brand colour

Success, warning and error should be unmistakably semantic. A single indigo “analytic” accent can add new-age energy without turning dashboards into a rainbow.

Typography audit: Outfit + Inter + JetBrains Mono is a sound trio. Keep it, but give each a strict job. EB Garamond and Cedarville Cursive should stay opt-in for authored learning content—not platform chrome or dense data UI.

The recommendation

“Bayes Signal”

An evolution of the current brand, not a costume change. Deep Atlantic ink makes the product feel more assured; sharper teal retains continuity; reserved indigo distinguishes insights, intelligence and advanced modes.

“Professional from the first screen; distinctive once you begin to use it.”

04 · Typography that supports the palette

Keep the family. Tighten the roles.

The existing font choices are thoughtful. The visual gain comes from restraint: one expressive face for hierarchy, one workhorse for interfaces, and mono only where precision earns it.

Recommended platform voice

Designed for clear thinking.

Inter makes long forms, tables and navigation quietly legible. Outfit adds a distinct, confident voice to headings and brand moments without sacrificing an enterprise feel.

Outfit 600–700  →  headings, brand, key metrics
Inter 400–600  →  product UI, body, data labels
JetBrains Mono 400–500  →  code, IDs, timestamps, technical values

Rules that make it feel premium

01
Let Inter do dense work

Use it by default in inputs, tables, body copy and navigation. It will make multi-app consistency feel more intentional.

02
Use Outfit as a signal, not wallpaper

Headings, high-level metrics and product identity only. Prefer 600/650 over extra-bold to keep the tone composed.

03
Keep editorial faces out of chrome

EB Garamond and Cedarville Cursive are useful learning-content tools; they should not define navigation, dashboards or forms.

Use the indigo accent for an insight label or annotation—not for text hierarchy. Typographic hierarchy should still work in grayscale.
05 · Make the decision real

The most important change is
semantic, not cosmetic.

There are already several token names and many direct hex values across the shared UI package and applications. Establish one canonical layer first; migrate components next.

Recommended sequence

Adopt Bayes Signal with low migration risk.

Do not replace individual colours page-by-page. Centralize decisions so changing a direction later is inexpensive and apps cannot silently drift apart again.

  1. Choose one naming convention: --bs-color-* semantic tokens, with aliases only while migrating.
  2. Publish foundations in packages/ui/src/styles.css; then have auth, super and wireframes consume them.
  3. Replace hard-coded fallback colours in atoms and shared molecules before polishing individual screens.
  4. Validate text, icons, controls and charts at WCAG AA contrast; test the dark sidebar and all focus rings separately.
  5. Reserve analytic indigo for deliberate components: Insight, AI-assist, forecasting and comparison—not generic decoration.
