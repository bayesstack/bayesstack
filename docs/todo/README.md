# BayesStack Daily TODOs (`docs/todo/`)

This directory contains daily task lists and roadmap items decided on specific dates.

## File Naming Convention

Files use a human-readable `DD-MMM-YYYY.md` date format (day-month abbreviation-year in lowercase):

```text
docs/todo/
├── README.md
├── 02-sep-2026.md
└── 15-oct-2026.md
```

### Format Details:
- `DD`: 2-digit day (e.g. `02`, `15`, `31`)
- `MMM`: 3-letter month abbreviation in lowercase (e.g. `jan`, `feb`, `mar`, `apr`, `may`, `jun`, `jul`, `aug`, `sep`, `oct`, `nov`, `dec`)
- `YYYY`: 4-digit year (e.g. `2026`)

Each daily file records actionable items, features, and architectural goals established on that date.
